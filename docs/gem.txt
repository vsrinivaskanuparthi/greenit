CURRENT KNOWN DESIGN
The project has a custom static code scanner.
It reads code structure and checks selected rules.
It does not directly measure electricity or carbon per line of code.

Source-only uploads provide findings.
Do not assume uploaded applications execute automatically.

The latest supplied demo is an Express reference-data caching example:
- Before: read and parse the same JSON file for every request.
- After: load and parse once at startup, then reuse the data.
- Both versions return the same response.
- The trusted example runner compares both versions using the same test.

Its carbon calculation uses measured test duration with assumed power
and an assumed electricity emissions factor.
Actual electricity consumption is not measured.
A shorter test produces a lower estimate under these assumptions.
It does not prove actual emissions savings.

CO2.js is separate:
It estimates emissions from data-transfer inputs.
It does not scan source, collect traffic or suggest fixes.
Do not attribute the caching demo’s compute estimate to CO2.js.
Do not combine estimates with overlapping boundaries.

Treat all previously reported benchmark numbers as historical examples.
Use actual current results for new comparisons.
